# Лабораторная работа №28 — шаблон MVP

**Тема:** AMFIBIA — маркетплейс брендовой одежды. Это настольная WPF-версия части сайта
[Fashion_site](https://github.com/JLeizy/Fashion_site): вход в аккаунт, каталог и корзина.

## Что умеет программа

- **Вход в аккаунт** по тестовым пользователям сайта, с проверкой email и пароля и заблокированным аккаунтом.
- **Каталог** — 714 настоящих товаров 15 модных домов (Balenciaga, Prada, Chanel, Chrome Hearts…):
  поиск, фильтр по бренду и разделу, сортировка по цене и названию.
- **Карточка товара** — описание, цена и размеры по размерным сеткам сайта.
- **Корзина** — добавление с выбором размера, удаление, промокоды, сумма, скидка и итог.

## Как открыть и запустить

1. Открыть **Visual Studio 2026** → «Открыть проект или решение» → `Lab28_MVP.sln`.
   Нужна рабочая нагрузка «Разработка классических приложений .NET» (.NET 10).
2. Нажать **F5**.
3. Войти: **`buyer@amfibia.by`**, пароль **`Amfibia2026`**.

| Аккаунт | Что покажет |
|---|---|
| `buyer@amfibia.by` | Покупатель Ева Лисовская |
| `owner@amfibia.by` | Создатель магазина |
| `blocked.user@example.com` | Ошибка «Аккаунт заблокирован» |

Промокоды: `AMFIBIA10` (−10 %), `GOTHIC15` (−15 %), `WELCOME20` (−20 %).

## Как работает MVP

### Окно входа — те же 7 шагов, что в методичке

1. **Вид** (`LoginWindow`) показывает форму входа.
2. **Пользователь** вводит email и пароль и нажимает «Войти».
3. **Вид** перехватывает нажатие (`LoginButton_Click`) и передаёт его представителю
   через событие `LoginRequested`.
4. **Представитель** (`LoginPresenter`) обрабатывает данные: обрезает пробелы у email и проверяет,
   что поля заполнены и email похож на email. Затем передаёт их модели: `model.Login(email, password)`.
5. **Модель** (`AuthModel`) ищет пользователя и обновляется: заполняет `LoggedUser` и `Message`.
6. **Представитель** берёт обновлённую модель. Если вход не удался, передаёт виду текст ошибки
   `model.Message`. Если удался, сообщает приложению событием `LoginSucceeded`.
7. **Вид** показывает ошибку, или приложение открывает окно магазина.

### Окно магазина — пример «В корзину»

1. Пользователь выбирает товар и размер и нажимает «В корзину».
2. `ShopWindow` передаёт нажатие событием `AddToCartRequested`.
3. `ShopPresenter` проверяет, что товар и размер выбраны (иначе «Выберите размер.»),
   и вызывает модель: `cart.Add(product, size)`.
4. `CartModel` применяет правила: вещь с ресейла бывает только в одном экземпляре,
   одного товара не больше 10 штук. Затем обновляет список и суммы.
5. `ShopPresenter` берёт из модели товары, сумму, скидку и итог, форматирует их («12 510 BYN»)
   и передаёт виду: `view.ShowCart(...)`.
6. `ShopWindow` показывает корзину.

**Главное правило:** вид не проверяет и не считает, модель ничего не знает про окна.
Представитель работает с окнами только через интерфейсы `ILoginView` и `IShopView`.

## Кто за что отвечает

| Действие | Вид | Представитель | Модель |
|---|---|---|---|
| Вход | форма, текст ошибки | проверка заполнения и формата email | поиск пользователя, пароль, блокировка |
| Поиск и фильтры | поля и списки | читает фильтры, выводит «Найдено товаров: N» | `CatalogModel.Search` |
| Карточка товара | текст, кнопки размеров | собирает описание, форматирует цену | `CatalogModel.GetSizes` |
| Корзина | таблица, суммы, сообщения | проверка выбора, формат сумм | `CartModel.Add / Remove` |
| Промокод | поле ввода | убирает пробелы, переводит в верхний регистр | `CartModel.ApplyPromoCode` — существует ли и действует ли сейчас |

## Откуда данные

- **Товары** — `Data/catalog.json`, выгрузка из `db/content/catalog/*.json` сайта по правилам `db/seed.js`.
  Тот же набор товаров и те же цены, включая расчётную цену для товаров без цены (`fallbackPrice`).
  Цвета, материалы и пол на русском взяты из `public/i18n/ru.json`.
- **Размеры** — как в `db/seed-data/sizes.js`: одежда, обувь (мужская, женская, унисекс), кольца,
  объём флакона, единый размер OS.
- **Пользователи** — тестовые аккаунты из `db/seed-data/users.js`.
- **Промокоды** — из `db/seed.js`, вместе со сроками действия.
- Фотографии товаров в программу не включены: в README сайта сказано, что они принадлежат правообладателям.

## Проверки ввода

| Где | Ввод | Сообщение |
|---|---|---|
| Вход | пустой email | Введите email. |
| Вход | `buyer` | Email указан неверно. Пример: buyer@amfibia.by |
| Вход | пустой пароль | Введите пароль. |
| Вход | неверный пароль | Неверный email или пароль. |
| Вход | `blocked.user@example.com` | Аккаунт заблокирован. Обратитесь в поддержку: support@amfibia.by |
| Корзина | товар не выбран | Сначала выберите товар в каталоге. |
| Корзина | размер не выбран | Выберите размер. |
| Корзина | вещь с ресейла второй раз | Эта вещь с ресейла есть в единственном экземпляре и уже лежит в корзине. |
| Промокод | пусто | Введите промокод. |
| Промокод | `SALE50` | Промокода SALE50 не существует. |
| Промокод | `AMFIBIA10` после 31.12.2026 | Срок действия промокода AMFIBIA10 закончился 31.12.2026. |
