# Лабораторная работа №28 — шаблон MVP

**Тема:** конвертер валют по официальному курсу Национального банка Республики Беларусь (НБРБ).
Пересчёт BYN ↔ USD / EUR / RUB / PLN / CNY. WPF-приложение на .NET 10.

## Как открыть и запустить

1. Открыть **Visual Studio 2026** → «Открыть проект или решение» → `Lab28_MVP.sln`.
   Нужна рабочая нагрузка «Разработка классических приложений .NET».
2. Нажать **F5**.

При запуске программа сама пробует загрузить курсы на сегодня с API НБРБ
(`https://api.nbrb.by/exrates/rates?periodicity=0`). Если интернета нет, она работает
со встроенными курсами НБРБ на 19.11.2026. Источник курсов виден в строке состояния внизу окна.

## Как работает MVP в этой программе

Те же 7 шагов, что в методичке:

1. **Вид** строит интерфейс. Представитель заполняет его данными модели: списки валют и таблицу курсов.
2. **Пользователь** вводит сумму, выбирает валюты и нажимает «Конвертировать» (или Enter).
3. **Вид** перехватывает нажатие (`ConvertButton_Click`) и передаёт его представителю
   через событие `ConvertRequested`.
4. **Представитель** проверяет сумму (`TryParseAmount`) и, если всё верно, передаёт данные модели:
   `model.Convert(amount, from, to)`.
5. **Модель** пересчитывает сумму через белорусский рубль и обновляет свои свойства
   `Result`, `CrossRate` и другие.
6. **Представитель** берёт обновлённые данные модели и передаёт их виду: `view.ShowResult(...)`.
7. **Вид** показывает результат, например `100,00 USD = 299,50 BYN`.

Вид не считает и не проверяет данные, модель ничего не знает про окно.
Представитель работает с окном только через интерфейс `IConverterView`.

## Формула пересчёта

НБРБ публикует курс за `Scale` единиц валюты. Например, `100 RUB = 3,6533 BYN`, `1 USD = 2,9950 BYN`.

```
курс за 1 единицу = OfficialRate / Scale
сумма в BYN       = сумма × курс_исходной_валюты
результат         = сумма в BYN / курс_целевой_валюты
```

Пример: `1000 RUB → USD = 1000 × 0,036533 / 2,9950 = 12,20 USD`.

## Проверка ввода (Представитель)

| Ввод        | Сообщение                                           |
|-------------|-----------------------------------------------------|
| пусто       | Введите сумму.                                      |
| `abc`       | Сумма должна быть числом, например 150 или 99,50.   |
| `-5` или `0`| Сумма должна быть больше нуля.                      |
| `10,555`    | Укажите не больше двух знаков после запятой.        |
| `5000000000`| Слишком большая сумма: максимум 1 000 000 000.      |

Принимаются и запятая, и точка: `99,50`, `99.50`, `1 500`.
